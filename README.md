# Система учета фотографий с мероприятий

Веб-приложение на фреймворке Django для автоматизации сбора, структурирования и поиска медиафайлов с публичных и корпоративных мероприятий. Проект позволяет ивент-менеджерам вести списки гостей, распределять снимки по альбомам событий, а участникам — мгновенно находить кадры со своим участием.

## Использованный технологический стек
*   **Бэкенд-фреймворк:** Python 3.11+ / Django 5.2 (LTS)
*   **База данных (ORM):** СУБД SQLite (интегрирована через Django ORM моделей)
*   **Фронтенд-слой:** HTML5 / Движок шаблонов Django Template Language (DTL)
*   **Стилизация интерфейса:** CSS3 / Сетка и компоненты фреймворка Bootstrap 5.3 (подключен через CDN)
*   **Качество кода и тесты:** статический линтер flake8, юнит-тестирование pytest

## Описание объектных моделей (Django ORM)
Взаимодействие компонентов системы построено на объектных связях между приложениями Django:
1.  **Event (Мероприятие):** ключевая сущность (дата, название, описание, место). Обладает автоматической сортировкой по календарной дате (`ordering = ['date']`).
2.  **Album (Альбом):** логическая папка внутри события. Связана с моделью `Event` отношением «Один-ко-многим» (`ForeignKey`).
3.  **Participant (Участник):** карточка гостя/спикера (ФИО, email, роль). Хранится в изолированном приложении `participants`.
4.  **Photo (Фотография):** медиафайл (разрешение, URL). Связан с `Album` через `ForeignKey`, а с `Participant` — через `ManyToManyField`, обеспечивая разметку и тегирование людей на снимках.

## Реализованные веб-страницы и маршруты
Маршрутизация проекта разделена на два уровня (корневой `urls.py` проекта и локальные `urls.py` приложений):
*   `http://127.0.0.1:<port>/` — Главная страница сайта. Отображает интерактивную сводную статистику СУБД (количество событий, фото, гостей) и меню навигации.
*   `http://127.0.0.1:<port>/events/` — Список всех мероприятий.
*   `http://127.0.0.1:<port>/events/<id>/` — Детальная карточка выбранного события со списком вложенных в него фотоальбомов.
*   `http://127.0.0.1:<port>/participants/` — Реестр всех зарегистрированных в системе участников.
*   `http://127.0.0.1:<port>/participants/<id>/` — Карточка участника с его профилем и автоматической плиткой из фотографий, на которых данный человек был отмечен.
*   `http://127.0.0.1:<port>/admin/` — Панель администратора Django для тотального управления данными и разметки.

## Инструкция по установке и локальному запуску

1. **Установите зафиксированные зависимости окружения:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Сгенерируйте файлы миграций базы данных на основе моделей ORM:**
   ```bash
   python manage.py makemigrations participants
   python manage.py makemigrations events
   ```

3. **Примените миграции (создайте таблицы в локальной СУБД SQLite):**
   ```bash
   python manage.py migrate
   ```

4. **Создайте учетную запись суперпользователя для доступа к админ-панели:**
   ```bash
   python manage.py createsuperuser
   ```

5. **Запустите встроенный веб-сервер разработки Django:**
   ```bash
   python manage.py runserver
   ```
После этого откройте в веб-браузере адрес: **`http://127.0.0`**

6. **Проверка качества исходного кода линтером (PEP 8):**
   ```bash
   flake8 . --max-line-length=120 --extend-exclude=venv
   ```
